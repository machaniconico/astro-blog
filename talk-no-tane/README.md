# 🌱 トークのタネ

雑談配信のネタ（話のタネ）を探すための総合サイト。
ランダムガチャ・カテゴリ別一覧・キーワード検索で、配信のトークテーマがすぐ見つかります。

[Astro](https://astro.build) 製の静的サイトで、サーバー不要・完全クライアントサイド動作。
Cloudflare Pages などの静的ホスティングにそのままデプロイできます。

## 機能

- **🎲 ネタガチャ** — ボタンを押すだけでランダムに話題を1つ表示。カテゴリ絞り込み・履歴つき。
- **🔎 ネタ一覧・検索** — 全ネタをキーワード／カテゴリで絞り込み。
- **🗂 カテゴリ別ページ** — 15ジャンルから話題を探す。
- **📅 今日のネタ** — 日付ベースで毎日切り替わるおすすめ（サーバー不要の決定的選出）。
- **📋 ワンタップコピー** — 気に入ったネタを配信メモへすぐコピー。

## ネタの追加・編集

すべてのデータは型付きの TS ファイルで管理しています。

- カテゴリ: [`src/data/categories.ts`](src/data/categories.ts)
- ネタ本体: [`src/data/topics.ts`](src/data/topics.ts) の `raw` 配列に
  `['お題', 'カテゴリID', '深掘りヒント(任意)']` を追加するだけ。

## 開発

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/ に静的ファイルを出力
npm run preview  # ビルド結果をプレビュー
```

Node.js 22.12 以上が必要です。

## ディレクトリ

```text
src/
├── data/         # カテゴリ・ネタのデータ
├── layouts/      # 共通レイアウト
├── components/   # Header / Footer / TopicCard
├── pages/        # 各ページ（ファイルベースルーティング）
└── styles/       # グローバルCSS
```
